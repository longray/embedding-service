## 一、项目概述

### 1.1 目标

为包装层服务添加记忆管理功能，实现：
1. **健康检查** - 统一监控所有服务状态
2. **记忆上传** - 批量转换向量并存储到知识图谱
3. **记忆搜索** - 向量搜索和关键词搜索

### 1.2 核心需求

```
用户需求：
1. /api/health  - 返回包装层、嵌入服务、LLM服务的健康状态
2. /api/upload  - 上传记忆，通过嵌入服务批量转换为向量，存储到SurrealDB，建立知识图谱
3. /api/search  - 查询记忆，从SurrealDB查询
```

### 1.3 技术栈

**现有**:
- FastAPI 0.109.0
- httpx 0.26.0 (HTTP客户端)
- pydantic 2.9+ (数据验证)
- structlog 24.1.0 (日志)
- prometheus-client 0.19.0 (监控)

**新增**:
- `surrealdb` - SurrealDB Python客户端
- `numpy` - 向量计算（可选）

### 2.2 数据流

**上传流程**:
```
用户 → /api/upload → MemoryManager
                         ↓
                    批量调用 Embedding Service
                         ↓
                    构建知识图谱
                         ↓
                    存储到 SurrealDB
                         ↓
                    返回结果
```

**搜索流程**:
```
用户 → /api/search → MemoryManager
                         ↓
                    生成查询向量 (Embedding Service)
                         ↓
                    向量搜索 (SurrealDB)
                         ↓
                    返回结果
```
