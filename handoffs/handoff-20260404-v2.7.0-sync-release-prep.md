### 技术发现与教训

- **Mock 返回值必须与透传行为一致**: sync_full 透传 upload_memories 时，mock 的 total/success 必须等于传入的 memories 数量，不能硬编码为 1
- **side_effect vs return_value**: 测试用 side_effect 模拟逐条调用时，如果实现改为一次性调用透传，必须同步更新测试 mock（BL-31 的 test_sync_full_with_failures 从 side_effect 改为 return_value）
- **BACKLOG 路线图与详情状态容易不一致**: 路线图写"✅ 已完成"但详情仍显示"📋 待开始"，需要双向同步
- **PowerShell 不支持 export**: git 命令前的 export 在 PowerShell 中报错，但不影响 git 命令执行
