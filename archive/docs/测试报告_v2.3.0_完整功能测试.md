所有测试均通过，未发现功能性问题。

### 轻微观察

1. **过滤功能**: 在测试 type 过滤时，结果中包含了部分 type=general 的记录，但这可能是因为搜索返回了所有匹配的结果，只是 type=code 的排在前面。功能本身正常。

2. **编码问题**: Windows 环境下 curl 命令行直接输入中文字符会有编码问题，需要使用 JSON 文件上传。这是环境限制，不是系统问题。
